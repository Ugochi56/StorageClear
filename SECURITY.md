# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in StorageClear (such as a privilege escalation bug in registry key removals or a path-traversal risk), please do **not** open a public GitHub issue. 

Instead, report it directly to the project maintainers via email at **security@storageclear.org**.

Please include:
* A detailed description of the vulnerability.
* A proof of concept (PoC) or step-by-step instructions to reproduce the issue.
* Any potential mitigation steps.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a security patch and public disclosure responsibly.
